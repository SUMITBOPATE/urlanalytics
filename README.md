# SHURL -Create WhatsApp links, QR codes and trackable short links for your business.

Create WhatsApp links, QR codes and trackable short links for your business.
A learning-focused full-stack URL shortener built from first principles.

The project will begin with Node.js's built-in HTTP module, then gradually add
Express, PostgreSQL, React, TypeScript, testing, and production safeguards.

## Planned features

- Create a unique short URL
- Redirect short URLs to their original destinations
- List and delete saved links
- Count clicks and display basic analytics

## Learning goals

- JavaScript and TypeScript fundamentals
- HTTP requests, responses, routes, and status codes
- Node.js and Express
- SQL and PostgreSQL
- React state, forms, effects, and API calls
- Testing and production basics

> The application is intentionally being built one small step at a time.
